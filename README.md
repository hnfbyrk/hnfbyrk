## Current Project

### LogInsightAI

A Python-based log analysis project designed to turn raw log data into clear operational insights.

Current capabilities:

- Parses text-based log files
- Counts `ERROR`, `WARNING`, and `INFO` records
- Calculates the overall error rate
- Classifies system status as `NORMAL`, `WARNING`, or `CRITICAL`
- Generates text and JSON reports
- Maintains a timestamped report history
- Handles empty log files safely
- Includes automated tests for core functions

Planned improvements include structured log parsing, command-line options, visual reporting, and anomaly-detection experiments.
