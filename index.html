LogInsightAI

Active development

A Python-based log analysis project that transforms raw operational logs into clear status information and reusable reports.

  • Parses text-based log files
  • Counts ERROR, WARNING, and INFO records
  • Calculates error rate and classifies system status
  • Generates text and JSON reports
  • Maintains timestamped JSONL history
  • Includes validation and automated tests
